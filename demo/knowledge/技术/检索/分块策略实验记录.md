# 分块策略实验记录

> 实验日期：2026-08-18。结论已吸收进《向量库选型对比》，本文保留过程，避免以后只看见一张表。

## 材料

教培混合样本：长教案 + 短错题。嵌入模型待定，所以数字只作相对比较。

## 结果

| 参数 | 现象 |
|------|------|
| 512 字，无重叠 | 召回偏低，短问答丢上下文 |
| 512 字 + 80 字重叠 | 短问答明显好转 |
| 1024 字 + 150 字重叠 | 长文档最好，短问答噪声大 |

## 先用的规则

短问答走 512+80，长文档走 1024+150，按资料类型分流，不在全局只留一套参数。
