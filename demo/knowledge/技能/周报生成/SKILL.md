# 周报生成

## 步骤

1. `list_kb_structure` 确认「运营/周报」下最近一期的编号与格式
2. `search_kb` 检索本周新增或更新的文档，范围覆盖知识库与会话
3. 读取 `技能/周报生成/模板.md`，按其结构组织内容
4. 每条进展必须给出来源文档路径，没有来源的不写
5. `write_doc` 写入 `运营/周报/<年>-W<周数>.md`

## 边界

- 不臆造未在知识库中出现的进展
- 与用户当次消息冲突时以用户消息为准
