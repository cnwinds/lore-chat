# 竞品调研

## 步骤

1. 读取 `技能/竞品调研/调研维度清单.md`，确认本次要覆盖的维度
2. `search_kb` 先看知识库里是否已有同一对象的调研，有则在其上更新而不是另起一篇
3. 联网检索每个对象的官方说明与一手资料，必要时抓取原页确认细节
4. 逐维度填表：每格要么给出有来源支撑的事实，要么写「未公开」，不留空、不猜
5. 表格之后写一节「我们的差异点」，只写与主人产品定位真实相关的对比
6. `write_doc` 落到「调研/」下

## 边界

- 一手来源优先：官方文档与定价页优于二手评测与营销稿
- 对比对象的选择要说明理由，不为凑数扩列
- 结论与推测分开写，推测明确标注
