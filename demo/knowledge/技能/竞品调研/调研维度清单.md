# 调研维度清单

固定七个维度，逐个填。信息未公开就写「未公开」，不留空、不用推测填充。

| 维度 | 要回答的问题 |
|------|--------------|
| 定位 | 它把自己说成什么？解决谁的什么问题？ |
| 目标用户 | 实际付费与使用的是谁？个人、教师、机构还是企业？ |
| 核心能力 | 拿掉营销词后真正做到的三件事是什么？ |
| 数据与隐私 | 数据存在哪？是否可本地部署或私有化？训练是否使用用户数据？ |
| 部署形态 | 云端 SaaS、私有化、桌面端还是自托管？运维成本落在谁身上？ |
| 定价 | 计价单位与门槛价；免费额度的真实边界 |
| 我们的差异点 | 对比之下我们真实占优或吃亏的地方，各写至少一条 |

写完自检：每格是否都能指回一个来源？「我们的差异点」是否只写了与本产品定位真实相关的对比？
