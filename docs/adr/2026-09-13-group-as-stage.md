# ADR 2026-09-13：群是独立现场（角色只投影卡片）

## 状态

已采纳（2026-09-13）。修订 [ADR 2026-09-12](2026-09-12-role-rooms.md) 第 5、6 条里「群经参与者并入角色时间线」的投影方式。引擎仍是 Actor / Room / Delivery / Wake。产品展开见 [product-role-rooms.md](../product/role-rooms.md)。

## 背景

P2 把 `kind=group` 做成左栏入口后，群被当成另一种 conversation 段灌进角色时间线，中栏也仍按一对一（user / assistant）画气泡。体验上：群没有头像；角色私聊里能看到整段群聊；群里看不出是谁在说话。主人要的是「几个人在一个群里聊天」，思考者仍是被 @ 的角色。

## 决策

1. **群是一等实体，像角色。** 有 id、标题、头像、成员。Agent 用 `list_groups` / `create_group` / `update_group` / `delete_group` 获取、创建、修改、删除；HTTP 同一套 Delivery。`list_rooms` / `create_room` 仍是兼容别名。
2. **群是唯一完整现场。** 中栏按说话人画：主人靠右；每个角色靠左，带头像和名字。思考、工具、回执都挂在该角色的气泡上。`@谁` 谁应。思考者仍是角色（人设 / 沙箱 / 工具），不是群自己。
3. **角色时间线不灌群全文。** `peer_dm` 仍上双方时间线。`group` 只投影一张 **参与卡片**（群头像、标题、自己上次发言摘要）；点卡片进群。没有自己回合则不出卡。
4. **群头像。** 可设自定义图；未设则用成员头像拼贴（与角色字母头像同一套）。

## 后果

- `conversations.avatar`；时间线 `kind=group_card`。
- 前端：群列表/顶栏头像；群消息按 speaker 排；角色时间线用卡片而不是群 transcript。

## 明确不采用

- 把群全文并进每个成员的角色时间线
- 群里继续用「当前助手」一种气泡、不标说话人
- 为群另做一套思考者（群没有人设，应者永远是角色）
