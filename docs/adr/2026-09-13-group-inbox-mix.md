# ADR 2026-09-13：群聊与角色混排在同一列表

## 状态

已采纳（2026-09-13）。修订 [ADR 2026-09-12](2026-09-12-role-rooms.md) 第 6 条「群聊左栏独立入口」的**导航呈现**，不改引擎：群仍是独立现场，见 [ADR 2026-09-13 group-as-stage](2026-09-13-group-as-stage.md)。

## 背景

左栏单独开一节「群聊」后，主人要在两个分类之间找对话。群和一对一角色都是「最近在聊的对象」，不应再按类型切开。

## 决策

1. **同一列表。** 角色与群按最近活动混排；不再出现「群聊」分组标题或独立滚动区。
2. **头像标记。** 群头像右下角加群标记（双人剪影）。自定义图与成员拼贴都带这个标记。
3. **一个加号。** 工具栏「＋」打开菜单：新角色 / 发起群聊。建群先圈选成员，名称可空（默认用成员名）。
4. **群仍是独立现场。** 点群进入群时间线；角色时间线仍只出参与卡片。不把群并进某个角色的私聊。

## 后果

- 左栏只保留一块对话列表 + 知识库。
- `GET /api/rooms` 为每个群带 `last_active_at` / `last_reply_preview`，用来和角色对齐排序与副标题。

## 明确不采用

- 用关键字或单独 Tab 把群从聊天列表里再拆出去
- 把建群做成「先填头像 URL 再勾复选框」的设置表单
