# 文档阅读区：两档侧栏宽度 + 专注阅读

日期：2026-07-11  
状态：待实现

## 问题

右侧文档预览固定为 `min(400px, 38vw)`，长文与表格可读性差。用户需要更大阅读空间，同时保留「扫一眼对照对话」的能力。

## 目标

1. 打开文档仍为侧栏预览（不打断对话）；首次默认窄档，关闭后记住窄/宽档位，下次打开沿用。
2. 侧栏支持两档宽度（窄 / 宽），宽档时对话仍可见。
3. 可进入专注阅读：对话隐藏，每次进入时文件树默认收起（可展开），文档占满主区域。
4. 从专注退出时回到进入前的侧栏档位；关闭文档回到纯对话布局。

## 非目标

- 不实现拖拽任意调宽。
- 不把宽度/专注偏好持久化到服务端（`docWidth` 可仅存本次会话内存；关闭文档后仍记住档位即可）。
- 不新增独立文档路由页。
- 不改后端 API。

## 方案概览

三档阅读体验：

| 档位 | 布局 | 用途 |
|------|------|------|
| 窄侧栏 | ~400px，对话正常 | 扫一眼、对照聊天 |
| 宽侧栏 | ~55–60% 宽，对话被挤窄但仍可见 | 边读边聊 |
| 专注阅读 | 对话隐藏；文件树默认收起可展开；文档占满 | 认真读长文/表格 |

## 状态模型（App 层）

| 状态 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `previewPath` | `string \| null` | `null` | 已有；当前预览文档 |
| `docWidth` | `'narrow' \| 'wide'` | `'narrow'` | 侧栏档位；关闭文档后仍保留 |
| `docFocus` | `boolean` | `false` | 专注模式；关闭文档时重置为 `false` |
| `sidebarCollapsed` | `boolean` | 每次进入专注时设为 `true` | 仅专注模式下有意义；专注期间可切换，再次进入专注会重新收起 |

## 布局规则

### 非专注（`docFocus === false`）

- 左栏：现有侧边栏（252px）。
- 中间：对话 `flex: 1`，始终可见。
- 右栏 `.doc-panel`：
  - `narrow`：`width: min(400px, 38vw)`，`min-width: 300px`（与现网一致）。
  - `wide`：`width: min(720px, 58vw)`，设合理 `min-width`（建议 ≥ 480px），避免挤垮对话。

### 专注（`docFocus === true`）

- 中间对话：隐藏（不卸载亦可，但不可见、不占位）。
- 左栏：默认收起为窄条（约 40px），点击展开回 252px；再点可收起。
- 文档区：占满剩余宽度。
- 正文：内容区 `max-width: ~760px` 居中，提升长文可读性；表格外层允许横向滚动。

## 交互

1. 打开文档 → 窄/宽侧栏（沿用上次 `docWidth`，默认窄），`docFocus = false`。
2. 标题栏「窄 ⇄ 宽」切换 → 只改 `docWidth`（仅非专注时显示）。
3. 「进入专注」→ `docFocus = true`，并将 `sidebarCollapsed = true`（每次进入都收起；专注期间展开/收起可切换）。
4. 「退出专注」→ `docFocus = false`，回到进入前的 `docWidth`。
5. 「×」关闭 → 清空 `previewPath`，`docFocus = false`；`docWidth` 保留。
6. 键盘：专注中 `Esc` → 退出专注；非专注且文档打开时 `Esc` → 关闭文档。

## 实现范围

| 位置 | 改动 |
|------|------|
| `App.tsx` | 状态与布局 class；按 `docFocus` 控制对话显隐 |
| `DocViewer.tsx` | 标题栏：窄/宽切换、进入/退出专注、关闭 |
| `Sidebar.tsx` + CSS | 专注模式下收起/展开窄条 |
| `index.css` | `.doc-panel--narrow` / `--wide`、`.app-shell--doc-focus`、正文 max-width、表格横向滚动 |

## 验收

- 窄 → 宽 → 专注 → 退出专注 → 关闭，全路径可用且状态正确。
- 宽档下对话区仍可见、可滚动、可发送。
- 专注下文件树可展开并切换文档，预览内容随之更新。
- 含表格的长文在宽档与专注下明显好读（表格可横向滚动，正文不过宽）。
- `Esc` 行为符合上文约定。
