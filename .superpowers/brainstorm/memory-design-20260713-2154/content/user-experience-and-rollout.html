  • “记住我所有 Python 项目都用 uv” → 立即确认
  • “我现在不做 A 了，改做 B” → 替代旧事实
  • “忘掉我住在哪里” → 删除并建立防复活记录
  • “你为什么认为我喜欢简洁？” → 展示原始证据来源
  • “你目前了解我什么？” → 展示当前核心画像
